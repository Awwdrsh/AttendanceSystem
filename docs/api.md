# API reference

Hajiri is a server-rendered Django app: browser pages and their HTMX partials are not an API. JSON endpoints exist for
what is not a browser page: Bearer-token integrations, the kiosk tablets, the public careers site and the group views.
They are Django REST framework views with the project's authentication (session cookie or `Authorization: Bearer
<token>` from `POST /api/v1/auth/login`), permission and error classes; errors are `{"error": "<message>"}` with the
status code.

- **Live, browsable reference:** `/api/docs` on a running install (Swagger UI, signed in), schema at `/api/schema`.
- **Schema file:** [`docs/openapi.yaml`](openapi.yaml), OpenAPI 3 generated by drf-spectacular. Regenerate it after
  changing an endpoint:

  ```sh
  cd server && .venv/bin/python manage.py spectacular --file ../docs/openapi.yaml --validate
  ```

- **Device gateway** (port 8080: ZKTeco ADMS `/iclock/*`, Hikvision `/hikvision/event`, `/health`, `/public-key`):
  see [`gateway.md`](gateway.md). Print the full URL map, pages included, with
  `server/.venv/bin/python scripts/django_routes.py --all`.
