# API reference

Hajiri's backend is a Django REST API under `/api/v1/`; the web app is the React app in `frontend/` (plain
JavaScript), which Django serves as its committed build. The endpoints keep the paths, methods, query parameters,
request bodies, JSON field names, status codes and error JSON of the TypeScript API the React app was written against
(git history, commit `65a9079`: `apps/api/src/modules/<module>/routes.ts`). They are Django REST framework views with
the project's authentication (the `hajiri_session` cookie, checked for the same origin, or `Authorization: Bearer
<token>` from `POST /api/v1/auth/login`), permission and error classes. Errors are `{"error": "<message>"}`, with
`details` or `issues` (`[{path, message}]`) where the TS API sent them.

- **Live, browsable reference:** `/api/docs` on a running install (Swagger UI, signed in as an admin), schema at
  `/api/schema`.
- **Schema file:** [`docs/openapi.yaml`](openapi.yaml), OpenAPI 3 generated by drf-spectacular. Regenerate it and
  this page after changing an endpoint:

  ```sh
  cd server && .venv/bin/python manage.py spectacular --file ../docs/openapi.yaml --validate
  .venv/bin/python ../scripts/api_reference.py
  ```

- **Every call of the web app has an endpoint:** `server/tests/web/test_frontend_api_paths.py` reads `frontend/src`
  and resolves each API path and method in Django.
- **Device gateway** (port 8080: ZKTeco ADMS `/iclock/*`, Hikvision `/hikvision/event`, `/health`, `/public-key`):
  see [`gateway.md`](gateway.md). Print the full URL map with `server/.venv/bin/python scripts/django_routes.py --all`.
